# 差旅报销台账系统 - 实施方案

## 📌 系统概述

将CSV格式的差旅报销数据导入到Web台账系统，实现数据的结构化管理、多维度查询和可视化展示。

**目标单位**: 南京三方化工设备监理有限公司

## 🎯 核心功能

### 1. 数据导入功能
- CSV文件上传解析
- 自动数据清洗和验证
- 员工编号自动匹配/新增
- 批量导入进度显示

### 2. 台账管理功能
- 报销单据列表展示
- 多条件筛选（人员、日期、合同、费用类型）
- 单据详情查看
- 状态流转管理

### 3. 统计分析功能
- 按人员统计费用
- 按合同统计费用
- 按费用类型统计
- 按时间维度统计
- 可视化图表展示

### 4. 数据导出功能
- 导出Excel报表
- 导出PDF报告
- 自定义导出字段

## 🏗️ 技术架构

### 前端技术栈
- HTML5 + CSS3
- JavaScript (ES6+)
- ECharts (图表)
- Papa Parse (CSV解析)
- XLSX.js (Excel导出)

### 数据存储
- LocalStorage (临时存储)
- IndexedDB (大数据量)
- 或后端API + 数据库

## 🔄 数据导入流程

```
1. 用户上传CSV文件
   ↓
2. 解析CSV数据（Papa Parse）
   ↓
3. 数据验证和清洗
   - 检查必填字段
   - 验证数据格式
   - 处理空值和异常值
   ↓
4. 员工编号匹配
   - 根据姓名匹配现有员工
   - 新员工自动生成编号
   ↓
5. 数据结构转换
   - CSV扁平结构 → 关系型结构
   - 主表 + 明细表分离
   ↓
6. 存储到数据库
   ↓
7. 显示导入结果
```

## 🔐 数据验证规则

### 必填字段
- 单据编号
- 报销人
- 费用日期
- 费用项目
- 报销金额

### 格式验证
- 日期格式：YYYY-MM-DD 或 YYYY/M/D
- 金额：数字，保留2位小数
- 发票号码：字母数字组合

### 业务规则
- 报销金额 > 0
- 费用日期 <= 当前日期
- 发票日期 <= 费用日期 + 30天

## 📝 注意事项

1. **编码问题**: CSV文件使用GBK编码，需要正确处理
2. **数据量**: 100+条记录，前端处理无压力
3. **浏览器兼容**: 建议Chrome/Edge最新版
4. **数据备份**: 定期导出数据备份
5. **权限控制**: 后期可添加用户权限管理
