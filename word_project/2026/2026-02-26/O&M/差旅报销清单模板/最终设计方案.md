# 差旅报销台账系统 - 最终设计方案

## 📌 需求确认

基于讨论结果，确定以下设计方向：

### 核心需求
1. **布局方式**：单一表格 + 灵活筛选器（方案2）
2. **表格字段**：13个核心字段
3. **分类方式**：多级分类（大类→子类→明细）
4. **员工编号**：外部导入（user表对应）
5. **合同关联**：项目名称自动匹配
6. **统计分析**：独立页面，全维度统计
7. **详情展示**：右侧抽屉
8. **数据导入**：支持CSV和Excel

### 功能优先级
1. 数据表格展示（分页、排序）
2. 多条件筛选（人员、日期、类型）
3. CSV/Excel数据导入
4. 单据详情查看
5. 新增/编辑报销单
6. 统计卡片（总金额、单据数）
7. 图表分析（柱状图、饼图）

## 🔍 多级分类筛选设计

### 费用分类体系

```
费用大类（一级）
├─ 差旅费
│  ├─ 国内差旅-餐费
│  ├─ 国内差旅-住宿
│  ├─ 国内差旅-交通
│  └─ 国内差旅-其他
├─ 招待费
│  └─ 业务招待费-餐费
├─ 通讯费
│  └─ 手机费用
├─ 培训费
│  └─ 培训费-系统费
└─ 其他费用
   └─ 其他-系统费
```

### 筛选器交互逻辑

1. **费用大类下拉框**
   - 选项：全部、差旅费、招待费、通讯费、培训费、其他
   - 选择后，费用子类自动更新对应选项

2. **费用子类下拉框**
   - 根据大类动态显示
   - 支持多选（复选框）

3. **级联筛选示例**
   ```
   用户选择：费用大类 = "差旅费"
   → 费用子类自动显示：
     □ 国内差旅-餐费
     □ 国内差旅-住宿
     □ 国内差旅-交通
     □ 国内差旅-其他
   ```

### 2. 筛选逻辑

```javascript
function filterData(data, filters) {
  return data.filter(item => {
    // 人员筛选
    if (filters.employee && item.employeeName !== filters.employee)
      return false;

    // 合同筛选
    if (filters.contract && item.contractId !== filters.contract)
      return false;

    // 日期范围筛选
    if (filters.dateStart && item.expenseDate < filters.dateStart)
      return false;
    if (filters.dateEnd && item.expenseDate > filters.dateEnd)
      return false;

    // 费用大类筛选
    if (filters.category && !item.expenseSubType.startsWith(filters.category))
      return false;

    // 费用子类筛选（多选）
    if (filters.subTypes.length > 0 && !filters.subTypes.includes(item.expenseSubType))
      return false;

    return true;
  });
}
```
