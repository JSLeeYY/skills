# 新需求核心业务流程图

## 1. 说明

- 本文覆盖新需求文档中`3-17`号核心业务功能。
- `1 资质`与`2 应用案例`属于背景信息，不单独绘制流程图。
- 流程设计结合了参考项目中已存在的近似能力：任务派工、交接、日志、周报、问题、文件、审批流、供应商端接口。

## 2. 体系文件管理

覆盖需求：`3 体系文件管理`

```mermaid
flowchart TD
    A[管理员规划体系目录] --> B[按类型上传技术文件 标准文件 法规文件]
    B --> C[系统生成目录 编码 版本和附件索引]
    C --> D[管理员审核并发布]
    D --> E[监造人员按目录检索 预览 下载]
    E --> F[在监造任务和质量计划中引用]
    F --> G[已审批通过的质量计划沉淀为标准模板]
    G --> H[后续新建质量计划时复用标准库]
```

## 3. 任务分配管理

覆盖需求：`4 任务分配管理`

```mermaid
flowchart TD
    A[项目负责人创建项目] --> B[按项目拆分采购包 形成监造任务]
    B --> C[维护任务范围 验收标准 关键节点 交付文件清单]
    C --> D[提交任务审批]
    D --> E{审批通过}
    E -- 否 --> C
    E -- 是 --> F[指定监理人员/采购包负责人]
    F --> G[系统下放任务级权限]
    G --> H[监理人员开展文件维护 进度跟踪 问题处理]
    H --> I{是否人员变更}
    I -- 否 --> J[持续执行任务]
    I -- 是 --> K[发起变更申请并说明原因]
    K --> L[审批通过后生成交接清单]
    L --> M[原监理人员提交交接]
    M --> N[新监理人员确认接收]
    N --> O[提交交接审批]
    O --> P{审批通过}
    P -- 否 --> M
    P -- 是 --> Q[系统回收原权限并授予新权限]
    Q --> R[留存交接记录和权责追溯链]
```

## 4. 策划管理

覆盖需求：`5 策划管理`

```mermaid
flowchart TD
    A[选择已审批监造任务] --> B[系统生成对应监造策划草稿]
    B --> C[自动带出任务基础信息]
    C --> D[上传合同附件并维护备注]
    D --> E[维护合同下多条物资信息]
    E --> F[监造人员预览合同和物资]
    F --> G[提炼合同关注点 关键点 风险点]
    G --> H[补充策划内容]
    H --> I[提交审批]
    I --> J{审批通过}
    J -- 否 --> H
    J -- 是 --> K[形成任务基线策划]
```

## 5. 供方文件审核

覆盖需求：`7 供方文件审核`

```mermaid
flowchart TD
    A[供应商上传质保大纲 制造质量计划等资料] --> B[系统绑定项目 采购包 监造任务]
    B --> C[形成供方资料台账]
    C --> D[审查人员在线填写审查意见]
    D --> E[上传佐证材料并补充见证点]
    E --> F[发起分级审批]
    F --> G{审批通过}
    G -- 否 --> H[退回供应商补正后重新提交]
    H --> C
    G -- 是 --> I[形成完整受控版本]
    I --> J[作为后续监造和质量计划的依据文件]
```

## 6. 质量计划标准建立

覆盖需求：`8 质量计划标准建立`

```mermaid
flowchart TD
    A[创建母计划 子计划 分计划] --> B[绑定项目 采购包 原材料 设备品类]
    B --> C[系统生成全局唯一编码和版本号]
    C --> D[编制工序与质控要求]
    D --> E[提交审核确认生效]
    E --> F{审核通过}
    F -- 否 --> D
    F -- 是 --> G[系统自动分解W R H见证点]
    G --> H[生成见证清单并分派执行]
    H --> I[监造人员按见证点记录时间 人员 结果 附件]
    I --> J{是否需要变更/升版}
    J -- 否 --> K[进入统计分析与报表]
    J -- 是 --> L[填写升版原因和更新说明]
    L --> M[归档旧版本并发布新版本]
    M --> G
```

## 7. 监造过程监督和执行

覆盖需求：`9 监造过程监督和执行`

```mermaid
flowchart TD
    A[监造人员选择监造任务] --> B{选择监督场景}
    B -- 日常监督 --> C1[记录生产工艺 设备状态 人员规范]
    B -- 质量计划执行 --> C2[按W R H见证点逐项执行]
    B -- 专项监督 --> C3[按专项主题 检查项 判定标准执行]
    B -- 巡检 --> C4[创建周度/月度巡检任务并执行]
    C1 --> D[上传现场照片 记录和附件]
    C2 --> D
    C3 --> D
    C4 --> D
    D --> E{是否发现问题}
    E -- 否 --> F[更新任务进度与统计数据]
    E -- 是 --> G[从业务记录直接发起问题单据]
    G --> H[进入问题闭环流程]
```

## 8. 监造质量问题处理

覆盖需求：`10 监造质量问题处理`

```mermaid
flowchart TD
    A[巡视 巡检 见证 验收 放行记录发现问题] --> B[快捷创建或手动新建单据]
    B --> C[自动带出项目 合同 制造厂等数据]
    C --> D[生成质量问题单/工作联系单/通知单编码]
    D --> E[提交审批流程]
    E --> F{审批通过}
    F -- 否 --> C
    F -- 是 --> G[系统推送给供应商指定接收人]
    G --> H[供应商填写整改措施 结果并上传佐证]
    H --> I[触发监造端复核待办]
    I --> J[监造人员现场复核或文件复核]
    J --> K{复核合格}
    K -- 否 --> G
    K -- 是 --> L[审批关闭单据并回写源业务状态]
    L --> M[记录关闭时间 形成双向追溯]
```

## 9. 监造巡查管理

覆盖需求：`11 监造巡查管理`

```mermaid
flowchart TD
    A[创建监造巡查计划] --> B[提交计划审批]
    B --> C{审批通过}
    C -- 否 --> A
    C -- 是 --> D[执行巡查并记录发现]
    D --> E[编制监造巡查报告]
    E --> F[生成行动项并分派责任人]
    F --> G[责任人落实整改并更新记录]
    G --> H[提交行动项关闭申请]
    H --> I{审核通过}
    I -- 否 --> G
    I -- 是 --> J[关闭单个行动项]
    J --> K{本次巡查行动项是否全部关闭}
    K -- 否 --> G
    K -- 是 --> L[巡查正式办结]
```

## 10. 抽查复验管理

覆盖需求：`12 抽查复验管理`

```mermaid
flowchart TD
    A[按合同创建抽验任务] --> B[指定抽验物项 检查人员 完成时限]
    B --> C[执行抽验复验]
    C --> D[录入检测指标 实测数据 结果判定]
    D --> E[上传图片 文件并给出整改建议]
    E --> F{是否不合格}
    F -- 是 --> G[转问题整改流程]
    F -- 否 --> H[记录合格结论]
    G --> I[更新抽验台账]
    H --> I
    I --> J[按合同 时间 类型生成统计分析报表]
```

## 11. 监造记录

覆盖需求：`13 监造记录`

```mermaid
flowchart TD
    A[监造人员填报日报] --> B[记录当日工作内容和异常问题]
    B --> C[上传附件并抓取当日相关监造文件]
    C --> D[系统按时间范围自动汇总日报]
    D --> E[生成周报/月报草稿]
    E --> F[监造人员调整时间范围和补充说明]
    F --> G[提交审批流程]
    G --> H{审批通过}
    H -- 否 --> F
    H -- 是 --> I[固化最终审批版]
    I --> J[归档 照片 报告 监督记录可追溯]
```

## 12. 监造完工管理

覆盖需求：`14 监造完工管理`

```mermaid
flowchart TD
    A[采购合同执行完毕] --> B[发起监造完工总结]
    B --> C[系统自动汇聚合同全生命周期监造数据]
    C --> D[自动生成完工总结初稿]
    D --> E[监造人员编辑 补充 修正]
    E --> F[提交审查]
    F --> G[系统推送至指定审查人]
    G --> H{总监批准}
    H -- 否 --> E
    H -- 是 --> I[系统汇总见证点 报表 异常问题]
    I --> J[按模板自动生成监造完工报告]
    J --> K[归档并进入追溯链]
```

## 13. 监造验收

覆盖需求：`15 监造验收`

```mermaid
flowchart TD
    A[发起预验收] --> B[上传会议纪要并支持预览下载]
    B --> C[登记遗留项 问题描述 责任人 时限]
    C --> D[跟踪遗留项整改进度]
    D --> E[责任人提交关闭申请和佐证附件]
    E --> F{复核通过}
    F -- 否 --> D
    F -- 是 --> G[遗留项关闭]
    G --> H[发起正式验收]
    H --> I[监造人员编制质量放行单并上传附件]
    I --> J[提交审核流程]
    J --> K{审核通过}
    K -- 否 --> I
    K -- 是 --> L[统计一次合格率并沉淀报表]
```

## 14. 监造放行

覆盖需求：`16 监造放行`

```mermaid
flowchart TD
    A[供应商登录系统] --> B[发起放行申请]
    B --> C[填写合同编号 物项名称 数量 日期]
    C --> D[上传申请佐证材料]
    D --> E[系统生成申请单号并推送待办]
    E --> F[监造人员查看申请详情]
    F --> G[补充审查资料和审查结论]
    G --> H[编制放行单]
    H --> I[提交审批]
    I --> J{审批通过}
    J -- 否 --> K[退回供应商补正]
    K --> B
    J -- 是 --> L[通知供应商发货]
```

## 15. 质量追溯

覆盖需求：`17 质量追溯`

```mermaid
flowchart TD
    A[输入采购物项编号或关键字] --> B[系统联查合同 供应商 文件]
    B --> C[聚合制造 检测 监造验收 出厂放行数据]
    C --> D[按时间轴展示全流程节点]
    D --> E[查看各节点表单 附件 结论]
    E --> F[下载相关文件]
    F --> G[形成完整追溯链和追溯报告]
```
