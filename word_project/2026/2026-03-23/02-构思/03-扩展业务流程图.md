# 新需求扩展业务流程图

## 1. 说明

- 本文覆盖新需求文档中`18-29`号扩展与支撑功能。
- 这些功能大多建立在核心业务链已经打通的前提下，通过统计、预警、识别、协同和经营辅助形成闭环。

## 2. 数据统计及质量趋势分析

覆盖需求：`18 数据统计及质量趋势分析`

```mermaid
flowchart TD
    A[采集物项 合同 见证 问题 放行等业务数据] --> B[按设备分类 装置分类 大件分类等维度汇总]
    B --> C[统计完成进度 合格率 到厂状态 不符合项]
    C --> D[生成趋势分析图和对比图]
    D --> E[在统计页面展示图表]
    E --> F[点击图表钻取明细数据]
    F --> G[输出分析报表]
```

## 3. 产品进度跟踪及风险预警

覆盖需求：`19 产品进度跟踪及风险预警`

```mermaid
flowchart TD
    A[系统实时汇聚质量问题 通知单 联系单数据] --> B[按预警规则计算风险分值]
    B --> C{是否达到预警阈值}
    C -- 否 --> D[持续监控]
    C -- 是 --> E[自动生成进度风险预警]
    E --> F[系统首页弹窗并推送责任人]
    F --> G[责任人跟进整改]
    G --> H{整改完成}
    H -- 否 --> F
    H -- 是 --> I[系统自动或人工解除预警]
    I --> J[形成预警处理闭环记录]
```

## 4. 防造假管理

覆盖需求：`20 防造假管理`

```mermaid
flowchart TD
    A[上传原材料证书 第三方复验报告 校准证书] --> B[系统自动触发防造假检测]
    B --> C[签字区域识别并与签字特征库比对]
    C --> D[印章区域识别并与印章模板库比对]
    D --> E[二维码解析并与备案信息交叉校验]
    E --> F{检测结果是否存疑}
    F -- 否 --> G[进入审核归档流程]
    F -- 是 --> H[生成造假预警和问题说明]
    H --> I[审核人员人工复核]
    I --> J{复核通过}
    J -- 否 --> K[驳回或标记高风险文件]
    J -- 是 --> G
    G --> L[归档前完成最终真实性确认]
```

## 6. 日常工作量化管理

覆盖需求：`22 日常工作量化管理`

```mermaid
flowchart TD
    A[管理员维护工作项和工日定额] --> B[形成定额版本并提交审批]
    B --> C{版本生效}
    C -- 否 --> A
    C -- 是 --> D[监造人员完成系统内任务]
    D --> E[系统自动匹配工作项和工日定额]
    E --> F[计入个人工日台账]
    F --> G{是否存在线下临时工作}
    G -- 否 --> H[进入统计]
    G -- 是 --> I[人工录入工作项和时长]
    I --> J[系统自动换算工日并校验异常]
    J --> K[提交审核]
    K --> L{审核通过}
    L -- 否 --> I
    L -- 是 --> H
    H --> M[按时间 工作项 合同包统计个人工日]
```

## 13. 培训与考试

覆盖需求：`29 培训与考试`

```mermaid
flowchart TD
    A[管理员创建培训] --> B[上传视频 PDF等资料并配置最短阅读时长]
    B --> C[配置总课时和培训对象]
    C --> D[学员学习并实时记录进度]
    D --> E[完成培训后提交心得和反馈]
    E --> F{是否配置为考试前置条件}
    F -- 否 --> G[可直接结束培训闭环]
    F -- 是 --> H[管理员创建考试并配置题型 时长 次数]
    H --> I[学员参加考试]
    I --> J[系统自动评阅客观题 人工评阅简答题]
    J --> K{是否通过}
    K -- 否 --> L[按规则要求重新培训后再考]
    L --> D
    K -- 是 --> M[系统生成或人工发放证书]
    M --> N[汇总培训课时 参与率 考试通过率等统计图表]
```
