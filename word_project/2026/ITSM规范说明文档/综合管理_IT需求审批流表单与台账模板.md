# 综合管理_IT需求审批流表单与台账模板

## 1. 文档目标

本文用于规范公司在数字信息化转型过程中的 IT 需求提报、变更、报价和优化管理，重点解决以下问题：

- 需求提出后缺少正式审批。
- 需求变更后无法追溯。
- 报价提报无固定流程，责任边界不清。

本模板适用于公司 `综合管理` 平台落地，可直接作为流程建表和台账设计依据。

## 2. 设计原则

- 所有需求先审批，后执行。
- 所有变更必须关联原需求编号。
- 所有报价必须关联需求或变更单据。
- 所有审批节点必须保留意见、时间、处理人。
- 所有流程完成后自动写入台账。

## 3. 编号规则

| 单据类型 | 建议编号 |
| --- | --- |
| 需求单 | `REQ-YYYYMM-####` |
| 变更单 | `CHG-YYYYMM-####` |
| 报价单 | `QUO-YYYYMM-####` |
| 优化单 | `OPT-YYYYMM-####` |

## 4. 流程一：需求提报审批流

### 4.1 建议流程

`申请人提报` -> `部门负责人审批` -> `信息部评估` -> `分管领导审批` -> `立项/驳回`

### 4.2 表单字段

| 字段名称 | 字段类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 需求编号 | 流水号/只读 | 是 | 系统自动生成 |
| 申请日期 | 日期 | 是 | 默认当天 |
| 申请部门 | 部门选择 | 是 | 发起部门 |
| 申请人 | 人员选择 | 是 | 发起人 |
| 需求标题 | 单行文本 | 是 | 简明描述需求 |
| 需求类型 | 下拉框 | 是 | 新增、改造、报表、接口、权限、其他 |
| 关联系统 | 下拉框 | 是 | 所属系统或模块 |
| 需求背景 | 多行文本 | 是 | 说明为什么提 |
| 需求内容 | 多行文本 | 是 | 说明要做什么 |
| 紧急程度 | 单选框 | 是 | 高、中、低 |
| 期望完成时间 | 日期 | 否 | 业务期望时间 |
| 是否需要报价 | 单选框 | 是 | 是、否 |
| 附件 | 附件 | 否 | 截图、文档等 |
| 信息部评估意见 | 多行文本 | 否 | 信息部填写 |
| 审批意见 | 审批意见 | 是 | 各节点自动留痕 |
| 最终结论 | 单选框/只读 | 是 | 通过、驳回、暂缓 |

## 5. 流程二：需求变更审批流

### 5.1 建议流程

`变更发起` -> `原申请部门确认` -> `信息部评估` -> `分管领导审批` -> `变更生效`

### 5.2 表单字段

| 字段名称 | 字段类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 变更编号 | 流水号/只读 | 是 | 系统自动生成 |
| 关联需求编号 | 关联表单 | 是 | 选择原需求 |
| 发起日期 | 日期 | 是 | 默认当天 |
| 发起部门 | 部门选择 | 是 | 变更提出部门 |
| 发起人 | 人员选择 | 是 | 变更提出人 |
| 变更类型 | 下拉框 | 是 | 范围、时间、金额、方案、其他 |
| 变更原因 | 多行文本 | 是 | 说明为何变更 |
| 变更前内容 | 多行文本 | 是 | 原确认内容 |
| 变更后内容 | 多行文本 | 是 | 新确认内容 |
| 是否影响时间/金额 | 单选框 | 是 | 是、否 |
| 信息部评估意见 | 多行文本 | 否 | 信息部填写 |
| 附件 | 附件 | 否 | 会议纪要、说明材料等 |
| 审批意见 | 审批意见 | 是 | 各节点自动留痕 |
| 生效结论 | 单选框/只读 | 是 | 生效、驳回、退回补充 |

## 6. 流程三：需求报价审批流

### 6.1 建议流程

`报价填报` -> `信息部复核` -> `使用部门确认` -> `财务确认` -> `领导审批` -> `报价生效`

| 字段名称 | 字段类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 报价编号 | 流水号/只读 | 是 | 系统自动生成 |
| 关联需求编号 | 关联表单 | 是 | 对应需求 |
| 关联变更编号 | 关联表单 | 否 | 如为变更报价则关联 |
| 申请日期 | 日期 | 是 | 默认当天 |
| 申请部门 | 部门选择 | 是 | 发起部门 |
| 申请人 | 人员选择 | 是 | 发起人 |
| 供应商名称 | 单行文本 | 是 | 报价主体 |
| 报价金额 | 金额 | 是 | 含税总额 |
| 交付周期 | 单行文本 | 是 | 如 20 个工作日 |
| 付款方式 | 多行文本 | 否 | 分期、验收后付款等 |
| 报价说明 | 多行文本 | 否 | 说明报价范围 |
| 报价附件 | 附件 | 是 | 报价单、清单等 |
| 信息部复核意见 | 审批意见 | 是 | 节点自动留痕 |
| 使用部门确认意见 | 审批意见 | 是 | 节点自动留痕 |
| 财务确认意见 | 审批意见 | 是 | 节点自动留痕 |
| 最终结论 | 单选框/只读 | 是 | 同意、驳回、退回补充 |

### 6.3 报价明细表

| 字段名称 | 字段类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 费用项 | 单行文本 | 是 | 如开发费、实施费 |
| 内容说明 | 单行文本 | 是 | 简要说明 |
| 数量 | 数字 | 是 | 项次或人天 |
| 单价 | 金额 | 是 | 单价 |

## 7. 流程四：需求优化审批流

### 7.1 建议流程

`优化申请` -> `业务负责人确认` -> `信息部评估` -> `审批通过后执行`

如优化内容已影响范围、金额或验收标准，则转入 `需求变更审批流`。

| 字段名称 | 字段类型 | 必填 | 说明 |

| 申请部门 | 部门选择 | 是 | 发起部门 |
| 申请人 | 人员选择 | 是 | 发起人 |
| 优化主题 | 单行文本 | 是 | 简明主题 |
| 优化说明 | 多行文本 | 是 | 说明优化内容 |
| 紧急程度 | 单选框 | 是 | 高、中、低 |
| 期望完成时间 | 日期 | 否 | 业务期望时间 |
| 信息部评估意见 | 多行文本 | 否 | 信息部填写 |
| 是否转变更 | 单选框 | 是 | 是、否 |
| 附件 | 附件 | 否 | 相关材料 |
| 审批意见 | 审批意见 | 是 | 各节点自动留痕 |
| 最终结论 | 单选框/只读 | 是 | 通过、暂缓、转变更、驳回 |

## 9. 综合管理平台配置建议

- 提交单据时自动生成编号。
- 审批通过后自动写入对应台账。
- 所有审批意见自动留痕，不允许后补。
- 驳回、退回、撤回记录必须保留。
- 查询条件建议至少支持：编号、部门、状态、时间区间。
