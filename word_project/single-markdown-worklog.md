### 验收标准-材料牌号下拉问题处理 SOP

#### 适用场景
- 材料牌号下拉框需要根据验收标准联动筛选。
- 原始控件联动配置会出现“下拉能筛出数据，但最终无论选哪个都回显成同一个牌号”的问题。

#### 最终可用 SQL
```sql
select a.* from 
(
    select 
        t2.id,
        t.standardname,
        t.id as ph_id
    from sys_standard t 
    left join sys_standard t1 on t.parent_id = t1.id
    left join sys_standard t2 on t1.parent_id = t2.id
    where t.type = 1
) a 
where 1 = 1
```

#### 控件配置
1. 数据集：`ds6`
2. 显示列：`standardname`
3. 数据列：`ph_id`
4. Web页面联动条件设置：`id=={e4}`
5. 需要勾选以下两个按钮：
   - `惰性初始化`
   - `每次输入时，动态数据过滤`

#### 结果
1. 下拉框可以正常打开并查询出对应数据。
2. 牌号显示正常，不再出现“选任意值最终都显示成同一个牌号”的问题。

#### 经验结论
1. 该问题的关键不是继续调整原有联动表达式，而是让下拉控件真正回写牌号自身唯一值。
2. 在当前场景下，`ph_id` 作为数据列、`standardname` 作为显示列，是已验证有效的组合。
