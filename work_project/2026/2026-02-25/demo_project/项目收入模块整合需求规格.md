## 一、角色与权限

### 1.1 角色划分（同合同台账）
| 角色 | 可见范围 |
|---|---|
| 项目总监 | 当前用户监管的项目下派单选用的合同号(CI编号)数据 |
| 项目经理 | 分配给当前用户的合同号(CI编号)数据 |
| 总监代表 | 当前用户负责的派单选用的合同号(CI编号)数据 |
| 合同负责人 | 当前用户作为合同负责人的合同号(CI编号)数据 |
| 财务/领导层/管理员 | 全部数据 |

> **来源：需求规格说明书+问答文档4月9日答复**
> - 在项目收入模块下，不使用"总监代表"概念，统一为"合同负责人"
> - 填报项目收入的是合同负责人（PECMS中一个合同只有一个负责人）

### 1.2 按钮级权限配置
以下按钮的权限需设置为**可配置项**：
- 当月确认产值填报
- 当月收入纠正
- 其他信息填报（区分为：开票信息填报 + 回款信息填报）

## 四、核心计算规则与逻辑

### 4.1 总产值
| 合同类型 | 计算方式 |
|---|---|
| 人工日 | 每日产值累加（合同单价 × 实际产生工时） |
| 人工日计算总价 | 每日产值累加（合同单价 × 实际产生工时） |
| 总价 | 等于已报收入 |

### 4.2 当月产值
| 合同类型 | 计算方式 |
|---|---|
| 人工日 / 人工日计算总价 | 监理编号下当月实际工时 × 合同单价 |
| 总价（未结束） | (已报收入 ÷ 所有工时) × 30 |
| 总价（已结束） | (总收入 ÷ 所有工时) × 30 |

### 4.3 确认总产值
- 三种合同一致：当月确认总产值累加

### 4.4 当月确认产值填报规则
| 合同类型 | 规则 |
|---|---|
| 人工日 / 人工日计算总价 | 合同负责人按时间区间填写，页面带出系统计算值。<br>**误差大的走审批流**（误差值在字典中配置） |
| 总价 | 按时间区间填写（无系统计算、无误差、无审批流） |

#### 产值计算规则补充（来源：4月14日文档）
- **人工时合同**下，一个监理驻场同时有三个项目时，打卡8个工时，**三个项目都记录8个工时**（不平均分）
- **总价包干合同**，计算产值时依然如此
- **成本**计算规则：按同一时间段项目叠加数量**平均分**，不分合同类型

### 4.5 已报收入
- 默认：开票金额合计
- 用户纠正时：开票金额合计 + 当月收入（当月收入需后期开票抵冲）

### 4.6 当月收入（财务纠正）
- 默认：开票金额
- 财务可纠正：选择合同并填写金额
- 选中的合同后续需开具发票抵冲

### 4.7 其他字段来源
| 字段 | 来源 |
|---|---|
| 开票总金额/最新开票时间 | 开票管理/发票最后上传时间 |
| 收款总金额/最新收款时间 | 回款管理/填报时输入 |
| 合同金额 | 同步PECMS监造金额 |
| 开票状态 | 未开票(0)/部分开票(0<X<合同金额)/全部开票(X=合同金额)；人工时合同直接显示"人工时定期据实结算" |

### 4.8 合同状态联动
- 合同状态变更为"已完成"时，若已报收入未达合同金额，**系统自动补齐已报收入**

## 五、表格操作栏（共5个按钮）

### 5.1 当月确认产值填报
- **弹窗内容**：
  - 基本信息区（不可编辑）：监理编号、合同名称、合同类型、合同金额、确认总产值
  - 可编辑区：当月确认产值输入框
  - 系统计算值展示（人工日/人工日计算总价合同时带出）
- **校验规则**：确认总产值 + 当月确认产值 ≤ 合同金额
- **按钮**：取消、暂存（不生效）、提交（生效）
  > 来源：4月14日文档明确要求"取消、提交、暂存三个按钮"

### 5.2 当月收入纠正（财务专用）
- **弹窗标题**：当月收入纠正（财务）
- **规则说明区**（黄色警示背景）：
  1. 选择合同并填写纠正金额，选中合同后续需开具相应发票抵冲
  2. 已报收入 = 开票金额合计 + 当月收入（纠正后需后期开票抵冲）
  3. 计算总金额时排除纠正金额
  4. 纠正原因为必填项，用于责任追溯
- **筛选区**：监理编号、合同名称、合同类型筛选
- **表格字段**（完整列表）：
  | 字段 | 说明 |
  |---|---|
  | 勾选框 | 多选 |
  | 监理编号 | CI编号 |
  | 合同名称 | 全名 |
  | 合同类型 | 人工日/总价/人工日计算总价（彩色标签） |
  | 委托方 | — |
  | 合同负责人 | — |
  | 当月产值(元) | 系统计算值 |
  | 已报收入(元) | 当前已报收入 |
  | 当月收入(元) | 当前当月收入 |
  | 开票总金额(元) | — |
  | 收款总金额(元) | — |
  | 纠正金额(元) | 可编辑输入框 |
  | 纠正原因 | 下拉必选（开票延迟/合同变更/计算误差/其他） |
- **底部信息栏**：已选合同数、纠正操作人、操作时间、纠正金额汇总
- **按钮**：取消、暂存（不生效）、提交（生效并后续计算）
- 提交后生成纠正记录，可在历史弹窗中查看

### 5.3 其他信息填报（区分两个入口）
> 来源：4月14日文档明确"其他信息填报应区分填报内容，分为开票信息填报和回款信息填报，而不是笼统的一个按钮"

#### 5.3.1 开票信息填报
- 计划开票时间（日期选择）
- 未开票原因（文本输入）
- 备注（文本输入）
- 按钮：取消、保存

#### 5.3.2 回款信息填报
- 最新收款时间（日期选择）
- 收款总金额（数字输入）
- 备注（文本输入）
- 按钮：取消、保存

> 均需生成历史记录（支持查询和分页）

### 5.4 历史记录（弹窗 Tab 切换）
> 来源：需求规格说明书 + 4月14日文档
> 核心要求：历史记录应区分为两个部分，在一个弹窗内，通过前置可点击按钮分开查询

#### Tab 1：当月确认产值（填报历史记录）
- **筛选条件**：时间区间、类型（系统计算/用户填报/系统补齐）、操作人、金额大小排序
- **表格字段**：
  | 字段 | 说明 |
  |---|---|
  | 月份 | 填报时间区间 |
  | 合同类型 | 彩色标签 |
  | 系统计算值(元) | 系统自动计算的参考值 |
  | 确认产值(元) | 用户填报的实际值（高亮对比） |
  | 差异值(元) | 确认产值 - 系统计算值（颜色区分增减） |
  | 差异率 | 百分比显示 |
  | 确认总产值快照(元) | 操作时刻的累计总产值 |
  | 类型 | 系统计算/用户填报/系统补齐 |
  | 操作人(项目负责人) | 填报人 |
  | 操作时间 | 精确到时分秒 |
  | 备注 | 操作说明 |

#### Tab 2：纠正记录（修改操作历史记录）
- **筛选条件**：操作人、监理编号、时间区间、类型（系统计算/系统补齐/用户纠正）
- **表格字段**：
  | 字段 | 说明 |
  |---|---|
  | 序号 | 行号 |
  | 监理编号 | CI编号 |
  | 合同名称 | 全名 |
  | 合同类型 | 彩色标签 |
  | 纠正前收入(元) | 纠正操作前的金额 |
  | 纠正金额(元) | 本次纠正增减额（红色高亮） |
  | 纠正后收入(元) | 纠正操作后的金额（蓝色高亮） |
  | 差异金额(元) | 颜色区分增减 |
  | 当月产值(元) | 参照对比 |
  | 纠正原因 | 开票延迟/合同变更/计算误差等 |
  | 类型 | 系统计算/系统补齐/用户纠正 |
  | 操作人 | 责任人 |
  | 操作时间 | 精确到时分秒 |
  | 状态 | 已生效/暂存/待审批 |

#### 底部数据说明
- 所有历史记录均不可修改或删除
- 每条记录包含操作人、精确操作时间、修改前后对比
- 用于责任划分和审计留痕
- 支持金额大小排序（来源：4月14日答复）

### 5.5 查看

## 六、关键业务约束（来源：问答文档汇总）

### 6.1 填报规则
1. 当月收入填报：**只有当月收入框可填写**，其余不可编辑
2. 其他信息填报：计划下次开票时间/未开票原因/备注是填写的
3. 合同金额：初始导入，不可编辑
4. 月产值：自动计算，不可编辑
5. 开票状态/开票总金额/收款总金额：抓取体现，不可编辑

### 6.2 历史记录要求
1. 历史记录应区分为**两个部分**（填报历史 + 修改历史）
2. 在一个弹窗内显示，通过前置可点击按钮分开查询
3. 查询后根据不同性质下数据进行筛选查询
4. 不需要按合同编号排序，做**金额大小排序**即可
5. 历史记录字段：合同编号、时间、金额、修改记录、项目负责人

### 6.3 开票/回款信息
1. 开票信息**不对接ERP**，从ERP导出后Excel导入
2. 新增开票记录字段：开票组织、开票客户、开票日期、发票号、币种、总数量、总金额、预计回款时间、合同负责人、监理编号(下拉)、项目名称(联动带出)、凭证号、备注
3. 开票回款提醒设置：合同类型、委托方、监理编号筛选，频率可选，推送站内消息至合同负责人
