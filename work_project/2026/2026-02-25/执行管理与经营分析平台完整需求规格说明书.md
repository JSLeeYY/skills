# 执行管理与经营分析平台完整需求规格说明书

## 一、 平台框架体系（3种方案待定）

- **方案一（RuoYi-Vue-Pro）**：使用若依前后端分离框架搭建综合管理平台，需维护用户、角色与组织架构信息。从 PECMS 平台进行单点登录跳转至综合管理平台。平台可独立登录使用。提供接口，在 PECMS 操作用户、角色、组织架构信息时进行同步操作。
- **方案二**：以服务形式提供接口，页面在现有 PECMS 进行开发，前端调用 PECMS 接口，由 PECMS 进行接口转发，服务与 PECMS 平台增加交互鉴权机制。无独立登录入口与页面，仅限配合 PECMS 使用。
- **方案三**：前后端另搭框架，无独立用户体系。用户在 PECMS 登录后由 PECMS 签发 Token（有效期与 PECMS 登录过期时间一致），前端调用服务时携带 Token，服务对 Token 进行鉴权，通过则放行请求。无独立登录入口与页面，仅限配合 PECMS 使用。

## 三、 核心业务模块需求明细

### 3.1 合同台账

- **角色划分**：
  - 项目总监：查看当前用户监管的项目下派单选用的合同号 (CI编号) 数据。
  - 项目经理：查看分配给当前用户的合同号 (CI编号) 数据。
  - 总监代表：查看当前用户负责的派单选用的合同号 (CI编号) 数据。
  - 合同负责人：查看当前用户作为合同负责人的合同号 (CI编号) 数据。
  - 财务、领导层、管理员：查看所有数据。
- **数据展示**：数据从 PECMS 中获取，列表展示字段包含：监理编号、合同名称、设备名称、委托方、制造方、监造金额、预给号时间、项目负责人、合同签订时间、合同原件返回情况时间、合同起始日期、合同终止日期、委托方联系人、合同形式、ERP录入情况、合同特殊情况备注、供公司平台项目编号、供公司平台项目名称。
- **查询筛选条件**：查询筛选条件在包含PECMS平台所有现有筛选项（监理编号、合同名称、设备名称、项目负责人、合同签订年份、委托方、制造方、监造金额、预给号时间、合同原件返回情况时间、合同起始/终止日期、委托方联系人、合同形式、ERP系统录入情况、合同特殊情况备注、公司平台项目编号/名称、使用的项目等19个维度）的基础上，由于经营分析的需要，只会比PECMS的条件更多、更细致。额外增加查询、重置、高级查询构造器，并支持按筛选条件自定义导出。
- **数据列操作按钮**：
  - **完成**：收款金额与合同金额一致时展示，点击弹出确认弹窗，确认后修改状态为“已完成”。
  - **终止**：除“已终止”外其余状态均展示，点击弹出确认弹框，确认后修改状态为“已终止”。
  - **取消终止**：“已终止”状态的数据展示。点击弹出弹窗包含[终止原因(必填)、预估时间(必填)、确定、取消]。点击确定调用接口发起审批流程。流程发起后，按钮变更为“取消终止申请”，点击“展示申请信息”可查看申请内容和审批信息。
- **详情查看**：弹窗展示当前选中合同的相关信息（含上述所有字段）。若有取消终止申请，同步展示记录信息（取消申请所有信息、发起人、提出时间、审批状态）。

### 3.2 项目收入

- **角色划分**：同“合同台账”逻辑。**备注**：当月确认产值填报、当月收入纠正、其他信息(开票/回款)填报按钮的权限需设置为可配置项。**注意：项目收入模块下彻底去除总监代表角色，统一为合同负责人。**
- **信息展示字段**：监理编号、合同名称、委托方、合同负责人、合同类型、合同金额、总产值(元)、当月产值(元/月)、确认总产值、当月确认产值(元)、当月确认产值最新填报时间、已报收入、当月收入、开票状态、计划开票时间、未开票原因、最新开票时间、开票总金额(元)、最新收款时间、收款总金额(元)、备注。
- **查询筛选条件**：监理编号、合同名称、委托方（及委托方类别判断，如中石化、中石油等）、合同负责人、合同类型、开票状态、计划开票时间、实际开票时间、实际回款时间、开票总金额、收款总金额、产值、确认产值等（执行过程中可增减）。支持全数据自定义列导出。
- **核心计算规则与逻辑**：
  - **总产值**：
    1. 人工日合同：每日产值累加 (合同单价 $\times$ 实际产生工时)。
    2. 人工日计算的总价合同：每日产值累加 (合同单价 $\times$ 实际产生的工时)。
    3. 总价合同：等于已报收入。
  - **当月产值**：
    1. 人工日合同 / 人工日计算的总价合同：监理编号下当月实际产生的工时 $\times$ 合同单价。
    2. 总价合同：项目未结束 = (已报收入 $\div$ 监理编号下所有工时) $\times$ 30；项目结束 = (总收入 $\div$ 监理编号下所有工时) $\times$ 30。
  - **确认总产值**：当月确认总产值累加（三种合同一致）。
  - **当月确认产值填报**：
    1. 人工日合同 / 人工日计算的总价合同：合同负责人按时间区间填写产值，页面带出系统计算值。误差大的走审批流（误差值在字典中配置）。产值超过合同金额也允许提交，但必须走审批流程（审批流表单需包含：超额原因(必填)、超额比例、是否有增补协议记录、附件上传等字段）。
    2. 总价合同：按时间区间填写产值（无系统计算、无误差、无审批流）。
  - **已报收入**：默认开票金额合计。用户纠正时，数据为开票金额合计 + 当月收入（当月收入需后期开票抵冲）。
  - **当月收入（财务纠正）**：默认开票金额，财务可纠正。纠正提供合同选择并填写金额，选中的合同后续需开具发票抵冲。
  - **其他字段来源**：
    - 开票总金额 / 最新开票时间：来源于开票管理/发票最后上传时间。
    - 收款总金额 / 最新收款时间：来源于回款管理/填报时输入。
    - 合同金额：同步 PECMS 监造金额。
    - 开票状态：未开票(0) / 部分开票(0 < X < 合同金额) / 全部开票(X = 合同金额)。人工时合同直接显示“人工时定期据实结算”。
    - 合同状态联动：合同状态变更为“已完成”时，若已报收入未达合同金额，系统自动补齐已报收入。
- **表格操作栏**：
  1. **当月确认产值填报**：弹窗展示基本信息(不可编辑)，提供可编辑输入框。**校验规则**：确认总产值 + 当月确认产值不可超过合同金额。
  2. **当月收入纠正**：无需审批流。弹窗需选择纠正金额来源的监理编号，纠正后需保证被追踪和溯源（包含来源监理编号、操作人、操作时间、原因）。按钮：取消、暂存(不生效)、提交(生效并后续计算)。累计总金额（已报收入）不直接排除纠正额，而是加上纠正额并在鼠标悬停时展示金额组成明细。
  3. **开票信息填报**：填报计划开票时间、未开票原因、备注。
   4. **回款信息填报**：填报计划回款时间、计划回款金额、最新收款时间、收款总金额、备注。考虑每个合同负责人填报自己名下监理编号的回款信息。这二者取代原笼统的其他信息。
  5. **历史记录（支持单合同与全局视图）**：除列表中行级历史外，需提供一个供领导层查看全部合同的全局历史入口，必须包含超详细字段及快捷查询。弹窗 Tab 切换：
     - Tab1 (当月确认产值)：筛选(时间区间、类型)。
     - Tab2 (纠正记录)：筛选(填报人、监理编号、时间区间)。展示字段：监理编号、名称、当月收入、当月产值、填报时间、填报人、类型（系统计算 | 系统补齐 | 用户纠正）。
  5. **查看**：跳转至执行管理页面，按监理编号展示数据。

### 3.3 执行管理

- **角色划分**：项目总监(监管项目的派单)、(大)项目经理(分配合同的派单)、总监代表(负责的派单)、合同负责人(作为负责人的合同派单)、领导层/管理员(所有数据)。**备注**：角色查看权限需设置为可配置项。
- **信息展示与计算（28个字段）**：
  - 基础关联：监理编号、合同负责人、项目编号、项目名称、项目总监、派单编号、总监代表、监造厂家、派遣人员、辅助人员、设备材料名称、设备数量。
  - **总产值**：人工日/人工日计算总价 = 每日产值累加；总价合同未结束 = (已报收入 $\div$ 所有工时) $\times$ 派单实际工时；结束 = (总收入 $\div$ 所有工时) $\times$ 派单实际工时。
  - **当月产值**：人工日/人工日计算总价 = 派单当月实际工时 $\times$ 合同单价；总价合同未结束 = (已报收入 $\div$ 所有工时) $\times$ 派单当月工时；结束 = 同理。
  - 监造方式：驻厂 / 巡检（图标或文字标识）。
  - 时间信息：计划开始/结束时间（**超期标红：当前列文字标红，并需展示超期天数，支持在表头按天数排序**）。实际开始时间（驻厂取首日日志时间；巡检取首次签到时间）。实际结束时间（驻厂取结束申请时间；巡检取末次签到时间）。
  - **项目执行状态（三色灯标识，可配置为字典）**：
    - 灰色(未开始)：当前时间 $\le$ 实际开始时间或无实际开始时间。
    - 蓝色(进行中)：实际开始时间 $\le$ 当前时间 $<$ 实际结束时间。
    - 绿色(已完成)：当前时间 $\ge$ 实际结束时间。
    - **红色/橙色(超期进行中)**：实际开始但已超过计划结束时间。
  - **用工时间**：未开始 = 空格；进行中 = 当前时间 - 派单实际开始时间；已完成 = 监造结束时间 - 派单实际开始时间。
  - 扩展配置（从 PECMS 获取判断）：是否使用监造平台、不使用说明、是否中石化项目。
  - **业务状态流**（驻厂有数据，巡检无数据）：大纲是否已编制审核、细则是否已编制审核、风险评估报告风险等级、依据性文件现场是否拿到、监理工程师交接申请、ITP 是否确认发给委托方、预检会是否召开。
- **表格操作按钮**：
  - **编辑**：修改上述业务状态流字段。对于非三方项目(未上PECMS平台)，若以下【技术文件】字段（1.大纲是否已编制审核 2.细则是否已编制审核 3.风险评估报告风险等级 4.技术协议等依据性文件现场是否拿到 5.监理工程师替换交接申请 6.ITP是否已确认并发给委托方 7.预检会是否召开并有会议纪要）发生缺失，必须标红警告，并通过弹窗供管理员补充填报。

### 3.5 开票明细管理

### 3.8 动态成本核算

#### A. 动态成本管理（主页）

- 角色：总监、经理、代表、负责人、财务/高层/管理员（权限配置项）。
- 一级页面展示：监理编号、合同名称、总工时、人员成本、差旅成本、固定支出成本。支持按监理编号查询。
- **备注要求**：**公式下组成需展示到前端；公式封装提取成工具类统一管理**。点击各项成本跳转相应二级明细页。

#### B. 二级页面明细

1. **人员成本清单页**：
   - 筛选：姓名、日期。表头：导出。
   - 表格字段：姓名、工时、个人成本(工时 $\times$ 单价)。
   - **核算规则**：列表以监理人员为维度。如一个人同时在三个派单，**成本 = 工时 / 派单数 (保留2位小数)**。
2. **固定成本支出清单页**：
   - 筛选：成本类型。表头：导出、新增。
   - 表格字段：成本类型、服务人员成本、资料费用、其他采购费用、金额、产生日期、录入人员。

#### C. 差旅报销管理（涵盖二级页功能）

- 角色设置探讨：按钮级别权限分配，后期待管理员调整。**每个人都有权限导入自己数据，调整金额只有财务和本人，本人只能按天数调整**。
- 字段及筛选：姓名、出差单编号、出差天数、分摊天数、差旅成本。支持编号/姓名筛选及导入。
- **操作栏调整逻辑**（核心）：以出差单为维度(一单一条)。点击调整弹窗展示关联的合同号，默认自动分配。提供手动调整（2种方式）：
  1. **按天调整**：总金额 / 天数。人为调整每个 CI 编号占据的天数来重算成本。
  2. **按金额调整**：总金额 / CI 编号数平均分配后，自行修改调整各 CI 所占金额。

#### D. 人员工资管理

- 角色：财务、人事。
- 字段与筛选项：账号、姓名、电话、部门、性别、工资。按姓名查询。
- 导入逻辑：支持单条/多条 Excel 导入。**若工资不符是否记录历史？**
- **脱敏要求（敏感项）**：数据密文存储。列表默认显示为 `****`，导出亦为 `****`。提供鼠标点击交互才展示明文工资。

### 3.9 利润管理

- **角色与权限**：总监、经理、代表、负责人、财务/高层/管理员。
- **基础列表**：展示监理编号、名称、负责人、委托方、制造方、总产值、总成本、利润。提供导出。
- **高亮逻辑**：利润 $\le 0$ 使用特定颜色；利润 $> 0$ 使用另一种颜色区分。
- **查询筛选**：以上述字段及时间范围自定义关联查询。
- **消息提醒机制**：当利润出现**负数**时，发送站内（PC+APP）提醒至对应合同负责人、项目经理、管理层及财务。
- **报表分析可视化**：点击列表“报表分析”跳转图表页。按筛选条件展示（支持多选折线图、柱状图等）。

### 3.10 经营数据量化

- **监理人员报表**：以辅助人员为维度。生成个人的产值、成本、利润报表。支持按年或时间段查询生成。支持自定义调整报表内容。*(注：需确认辅助人员是否可登录查看自身数据)*。
- **合同报表**：以监理编号为维度。生成产值、成本、利润、开票、回款等数据综合报表。支持导出 Excel 及自定义筛选和字段列。

## 4. 领导运营管理驾驶舱大屏 (Executive Dashboard)

在保证底层明细业务闭环的基础上，于系统最顶级增设专门向管理层汇报使用的全局大屏模块，抽取汇总以下核心维度：

- **4.1 财务北极星大盘**: 实时跳动展示当年累计确认产值、累计开票、累计已回款净流通现金、综合平均利润率及同比/环比走势。
- **4.2 经营风险穿透预警**: 重点滚动展现低利润/亏损警报项目(利润<0或介于0~3%)、逾期呆账重灾区榜单、以及进度严重超期的核心合同，确保雷区暴露。
- **4.3 成本与产值剪刀差走势**: 构建月度跨期的总发包支出(人工+差旅等)与总确权产值的双轴对比图，直观暴露效率瓶颈或利润剪刀差。
- **4.4 人源战力与效能透视**: 综合项目进度分析现场监理人均产值贡献度，以及资源驻点分配情况对比分析。
- **4.5 客户价值与健康度矩阵**: 加入按照主要委托方(甲方)划分的开票回款健康度星级矩阵或占比漏斗，展示哪些大客户才是公司的优质稳定现金牛，哪几家是拖欠重点。
