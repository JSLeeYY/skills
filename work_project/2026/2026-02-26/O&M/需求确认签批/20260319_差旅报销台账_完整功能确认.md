<span style="color:#2ecc71;">#### 9.5 差旅报销管理 - 页面设计规则与明细操作规程</span>

<span style="color:#2ecc71;">为保障财务操作的可溯源性并提供足够详尽的审计视图，差旅报销台账管理页面在检索与明细展示方面进行了深度的全景增强：</span>

<span style="color:#2ecc71;">**1. 第一层交互：主视图的搜索与检索枢纽**</span>
<span style="color:#2ecc71;">- **全新重构的筛选条件（抛弃冗余状态查询，转向资金流追溯）**：包含三大核心输入区域：</span>
<span style="color:#2ecc71;">  - **出差单编号**：文本输入框，带占位符，用于快速通过合同工单号直接捞取特定差旅记录。</span>
<span style="color:#2ecc71;">  - **姓名**：文本输入组件，用于按提交人员维度实施模糊查询，满足对某特定员工历史台账的调阅。</span>
<span style="color:#2ecc71;">  - **金额区间（最关键业务抓手）**：由于原本的“日期与状态”不具备实操中的差旅坏账核对意义，该字段被重构为一组双向输入框的联合体——包含一个【最小金额输入边界】与一个以 `~` 符号过渡的【最大金额输入边界】。财务能够通过“比如输入 5000 ~ 10000”直接精准捞出大额款项与特定的预算流转。</span>
<span style="color:#2ecc71;">- **筛选区域动作执行按钮**：</span>
<span style="color:#2ecc71;">  - **查询**（具有主视觉深蓝强调色的矩形确认按钮，附带搜索图标）：点击后前台捕获“单据+姓名+资金区间范围”并将这些复合型查询指令同时掷入底层拦截器进行数据匹配，即时过滤出符合三重要求的数据清单。</span>
<span style="color:#2ecc71;">  - **重置**（带有灰底浅白反差色的副操作按钮）：点击后触发输入域清空函数，销毁所有预设搜索值，自动重载全局完整差旅列表。</span>

<span style="color:#2ecc71;">**2. 第二层交互：外部全览表、全局与外挂按钮群**</span>
<span style="color:#2ecc71;">- **表头区域全局操作能力**：**导入**按钮（支持多流派文件输入 Excel 或 Word，点击文件被系统吃入后，内部钩子将自动落库，并横跨其他数据表与合同成本池发生关联分摊性重新调算）。</span>
<span style="color:#2ecc71;">- **表格内展信息矩阵**：姓名（单行左对齐）、出差单编号（系统分配唯一键号，渲染为醒目蓝色超链接可防呆跳转）、出差天数（居中统计值）、分摊天数（居中分配值）、差旅成本（右对齐排布、强制开启千分位格式化并自带人民币羊角符的数值字段）。</span>
<span style="color:#2ecc71;">- **操作栏行级功能（固定挂载于每行末端右侧）**：</span>
<span style="color:#2ecc71;">  - **调整**：延续原系统行为学，点击触发专门的重塑差旅成本配比弹窗（内含对"按天数维度调整"和"按强制输入金额维度调整"两套并列运算机制的支持）。</span>
<span style="color:#2ecc71;">  - **查看明细（全新下钻穿透能力补充）**：这是针对复杂出差费用明细的审计专用按钮。点击该蓝色空心悬浮按钮后，将不发生页面物理跳转，而是以遮罩 Modal 的形式升起覆盖全屏级的详细查验视图，下文即将展开针对该巨幅查看明细弹窗的 7 大全量细节定义。</span>
<span style="color:#2ecc71;">- **表内内联控制说明（延续原则）**：导入后的底层数据行部分依然保留允许内联唤醒双击编辑的功能（直接置灰底选中后在于列表中修改分摊额度或时效），并保留右侧调整按钮的弹窗机制作为安全兜底，共同确保资金数据的高度可控与准确修改。</span>

<span style="color:#2ecc71;">**3. 第三层交互：差旅明细全景查看弹窗（巨量数据归集地，1:1 复刻前端填报逻辑）**</span>
<span style="color:#2ecc71;">在老版本缺失展示载体的情况下，本轮修订彻底摒弃了拥挤的“简单超阔大宽表”拼凑思路，转而**通过极致对齐“新增报销单时的多表结构”将数据进行业务层级的多维切割展示**。当用户点击“查看明细”唤起弹窗后，会看到如下充满设计感与数据厚度的 7 重结构区：</span>
<span style="color:#2ecc71;">- **弹窗整体空间环境设定**：主标题为“📄 报销明细查看 - 假数据预览”。载体框突破了常规 600px 限制，自适应设定在了 1000px 的惊人展现广度（封顶可触及 90vw 宽边界），高度限制为最高不大于全屏的 70vh，搭配防撕裂平滑原生纵向滚动条，从底层构建了舒适的文本数据流呈现效果。通篇正文文字全部约束于系统内置的等宽非衬线类微软雅黑字体群（`Microsoft YaHei`, `sans-serif`）。</span>
<span style="color:#2ecc71;">- **① 基底溯源：基本信息追踪区（淡蓝色标识带）**：弹窗首段采用 `#e3f2fd` 淡青底色加上深天蓝（`#2196f3`）引言加粗竖线来界定这块纯阅读区域。界面利用 Grid 四分列设计，平滑排列上层暗灰色指导名称（如“单据编号”等）及下方对应的深黑色加大一号实体数据（如“E01797620251200001”编号文本、“李娜”姓名文本、“市场部”组织文本以及“APP-2026-0012”的原始发单申请号文本），从而构建整个单子的上下文语境。</span>
<span style="color:#2ecc71;">- **② 海量覆盖：通用费用信息清单区（淡绿色标识带）**：向下拉动后，以 `#e8f5e9` 清爽环保豆绿色背衬承载的是一块宽度惊人（强制支持不低于 3000px 的超级横向内滚动）的重度清单。表头包裹 26 列巨细无遗的字段防呆审阅（如费用承担成本中心、发票税额、税种、交易与付款双币种折算值、本位币比值、原发票各项时间锚点，再到详细的 WBS 预算及项目指向关联字段等）。每一行数据的外框都有隐式浅隔离条（`1px solid #eee`）划界，而其中的报销金额这一极其敏感的财务核拨目标，将会被强制加粗并以警告亮橙色（`#e65100`）脱颖而出，以吸引财务最后一道人工视线的驻留。</span>
<span style="color:#2ecc71;">- **③ 空间动线：差旅费用明细区（淡橙色标识带）**：承接下方的是以 `#fff3e0` 夕阳光晕暖色框为主体的差旅移动分析专区。内置 1400px 数据宽表承载出差轨迹，由 11 项明确动线字段支撑（如天数、被拖拽拆分的同行人员名单、差旅经停的始发地与目的地、严控双规起止时间区间、并辅以出行选择的交通工具大类及车厢特等坐席等级标准复核依据等），使财务能轻易捕捉任意出轨的超标行迹。</span>
<span style="color:#2ecc71;">- **④ 沟通成本：招待费用明细清单区（淡粉色标识带）**：为商务与公款吃喝的特殊招待建立了一条隔离防线 —— 采用 `#fce4ec` 浅红微暖背衬进行界定。这个表格宽度设为了庞大的 2200px 以承载 18 条超大密粒度字段：涵盖了招待对象（及对方头衔定位）、精准的双边列席数量约束（我方参与数、对方参与数）、招待地点定位、发单的主宴请人和其陪同者身份对照、针对酒精及特殊液体的敏感追查（例如酒水被细拆为消耗数量、单瓶采购价、总计购酒金额及最终领用消耗金额等细微拆分字段），更囊括了就餐的时间段捕获。针对没有公关费用的单子，则使用了友好的超大单元格跨度灰字提示“暂无招待费用数据”。</span>
<span style="color:#2ecc71;">- **⑤ 话补定额：手机通讯费用区（淡蓝色标识带）**：使用了极其理性的 `#e1f5fe` 冷色背景，高度凝缩为只有 3 列核心展示的宽表（脱敏格式输出的手机长列、受限周期的业务生效期间说明、以及写死的标准配给额度），展现清晰简单的包月发放逻辑。</span>
<span style="color:#2ecc71;">- **⑥ 杂费回收：其他费用明细区（淡紫色标识带）**：使用 `#f3e5f5` 特色紫罗兰强调包容性极杂的清单阵列，涵盖具有临时浮动属性的 6 列边缘数据采集（譬如涉及临时指派用餐产生的人数与人次计数、用于特批用车的车牌流转记录及其匹配的业务产生精准日期点等）。</span>
<span style="color:#2ecc71;">- **⑦ 落锤总结：全表横向汇总大金额展现区**：所有冗长的数据翻阅终止于弹窗右下角一块专门悬停的 `#f0f9ff` 淡蓝底色安全收据签押式色块中。此处抛却表格形态，转用直抒胸臆的结构化纯文字句式表达：“报销总额：”字眼后衔装着 22px 巨大尺寸的抢眼火橙色数字标签（例如：¥ 2,516.00），营造权威结论式的封印感。系统在下方统一排布了一枚具有深邃黑背与恰当内间距的交互按钮“关闭明细”，按下以撤销 Modal，令整体弹窗体验顺滑而体面。</span>
