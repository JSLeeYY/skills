   ```html
           <option value="admin">管理员/领导</option>
           <option value="李明">合同负责人-李明</option>

       </select>
   </div>
   ```

2. 在 app.js 中新增角色过滤函数：
   ```javascript
   function filterByRole(role) {
       const table = document.getElementById('executionTable');
       const rows = table.querySelectorAll('tbody tr');
       rows.forEach((row, index) => {
           const responsiblePerson = row.cells[2]?.textContent.trim();
           row.style.display = (role === 'admin' || responsiblePerson === role) ? '' : 'none';
       });
   }
   ```

**【业务规则】**：

- **合同负责人**：登录后只能查看自己名下的合同数据
- **管理员/领导**：可以查看全部合同数据
